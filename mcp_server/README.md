# Context Graph MCP Server

This directory contains the standalone MCP app for Context Graph.

## Structure

- `src/` — MCP implementation and tool registration
- `config/` — YAML configs and example client config
- `tests/` — MCP app tests
- `docker/` — container build assets

## Install

From the repo root:

```bash
uv sync --all-packages --dev --no-editable
```

This is the recommended local setup because Python 3.13 ignores hidden editable-install `.pth` files generated by `uv` workspaces, which can otherwise break the standalone MCP entrypoints.

## Run

HTTP:

```bash
uv run --package context-graph-mcp context-graph-mcp \
  --config mcp_server/config/config.yaml \
  --transport http
```

stdio:

```bash
uv run --package context-graph-mcp python -m src \
  --config mcp_server/config/config.yaml \
  --transport stdio
```

## Entry Points

Use `context-graph-mcp` or `python -m src`.
